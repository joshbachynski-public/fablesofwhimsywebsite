DROP YOUR PHOTOS IN THIS FOLDER
================================

The site is already wired to look for these exact filenames. Drop your
purchased photos here with these names and they appear instantly — no
code changes needed. (Until you do, the site shows tasteful painted
art-nouveau backdrops in your palette, so nothing ever looks broken.)

  tower-starfield.jpg    → Home hero + Book Club event
                           (the stone tower ruins looking up at the stars)

  coffee-books.jpg       → About page + Brunch & Bookstore Crawl event
                           (the two espresso cups beside the open book)

  key-book.jpg           → About page + Bookbinding Workshop event
                           (the antique key resting on an old book)

  library-archway.jpg    → Home feature + Masquerade event
                           (the grand library with the hidden brick archway)

TIPS
----
• JPG or WebP, landscape, ~1600–2400px wide is perfect for the web.
• Keep file sizes reasonable (aim < 500 KB each) so the site stays fast.
• Want a photo on a specific EVENT instead? Open
  assets/js/events-data.js and set that event's  image:  field to
  e.g.  "assets/img/your-photo.jpg".
